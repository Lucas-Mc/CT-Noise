
# Evaluation of Image Noise from Computed Tomography in an Organ-Specific Anthropomorphic Phantom

Code for the paper: "Evaluation of Image Noise from Computed Tomography in an Organ-Specific Anthropomorphic Phantom" found at: https://doi.org/10.48550/arXiv.2611.07357. The anonymized data is found at: https://doi.org/10.6084/m9.figshare.34913829.

## Installing proper requirements (on Windows)

1. Create python environment with Python 3.12.10: `python3.12 -m venv env_3-12-10`
2. Activate virtual python environment: `.\env_3-12-10\Scripts\activate`
3. Install packages: `pip install -r requirements.txt`
